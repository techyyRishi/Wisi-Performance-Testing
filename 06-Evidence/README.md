# Wisi – Performance Testing Evidence

Store only genuine screenshots and exports from the original Wisi JMeter work in this folder.

## Suggested Evidence

Create the following subfolders and place matching evidence inside them:

```text
06-Evidence/
├── Screenshots/
│   ├── 01-Test-Plan-Configuration/
│   ├── 02-Thread-Group-Configuration/
│   ├── 03-HTTP-Request-Configuration/
│   ├── 04-API-Responses/
│   └── 05-JMeter-Reports/
└── Exports/
    ├── JMeter-JTL/
    └── JMeter-HTML-Reports/
```

## What to Upload

### 1. Test Plan Configuration
- Screenshot showing `WISI Performance Testing`.
- Screenshot showing `User Journey` Thread Group.

### 2. Thread Group Configuration
- Screenshot showing number of threads, ramp-up period, and loop count.

### 3. HTTP Request Configuration
- HTTP Request Defaults.
- HTTP Cookie Manager.
- Login request configuration.
- Product/listing request configuration.
- Add to Cart request configuration, if available.

### 4. API Responses
- View Results Tree screenshots.
- Request and response details with sensitive values hidden.
- Response codes and error details.

### 5. JMeter Reports
- Summary Report.
- Aggregate Report.
- Response time graphs.
- HTML Dashboard.
- `.jtl` results, if available.

## Security Checklist

Before uploading:
- Remove or blur access tokens and refresh tokens.
- Remove cookies and session identifiers.
- Hide passwords, email addresses, and personal data.
- Remove private environment credentials.
- Confirm company/client approval for public sharing.

Only upload evidence that genuinely exists. Do not create illustrative screenshots and present them as actual test results.
